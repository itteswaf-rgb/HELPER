# HELPER frontend (Phase 1)

These files are served by the backend. Do not open them by double-click.
See ../README.md for install and run steps.

- index.html: Home
- pages/directory.html: searchable emergency contact directory
- pages/contact-details.html: record details and source evidence
- pages/login.html: admin sign-in
- pages/admin-dashboard.html: protected, read-only dashboard
- css/: style.css, responsive.css, app.css
- js/: api.js (shared helpers), public.js (public pages), admin.js (login + dashboard)
